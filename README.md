LensNest is an image-search app that will allow users to search for a topic and discover images in a responsive grid. I chose a teal and orange colour palette to give the app a fresh visual identity that is different from the reference design. I added quick-pick category chips so users can easily choose common topics, and a Clear button to make resetting the search simple. The results area is prepared as a responsive CSS Grid so image cards can be added in Part 2.
